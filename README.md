## Project Previews

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Small Language Model from Scratch</h3>
      <p><sub><b>INDIVIDUAL PROJECT</b></sub></p>
      <p>A 94.3M-parameter Llama-style model trained on 577.5M tokens, with a custom ~24K-vocabulary BPE tokenizer, GQA, RoPE and SwiGLU. Weights run in a single-file, dependency-free C runtime; <b>8.26 tokens/s reported</b> on a 2 GB Android phone.</p>
      <p><sub>PyTorch · C · BPE · GQA · RoPE · SwiGLU</sub></p>
      <p><a href="https://github.com/amartya-pandey/SLMa-94M-baremetal">Code</a> · <a href="https://huggingface.co/amartya-pandey/SLMa-94M">Model</a></p>
    </td>
    <td width="50%" valign="top">
      <h3>SatyaSetu</h3>
      <p><sub><b>TEAM PROJECT · I LED THE TEAM · SIH 2025 NATIONAL WINNER</b></sub></p>
      <p>Unified digital credential issuance and verification: blockchain-backed credentials plus AI forgery screening for legacy documents (OCR, custom YOLOv8 Nano seal localization, fine-tuned ViT-Base). <b>Reported:</b> 96% forgery-detection accuracy, 30 ms seal localization.</p>
      <p><sub>Python · YOLOv8 · ViT · OCR · Blockchain</sub></p>
      <p><a href="https://satyasetu.live/verify">Live demo</a></p>
    </td>
